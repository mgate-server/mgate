# Нагрузочное тестирование MGate

Проверка целевых показателей производительности: **до 50 сообщений/с на
4 vCPU / 8 GB RAM** и ответ Webmail/API ≤ 200 мс (p95).

## Статус

Скрипт `smtp_load.py` — рабочий генератор нагрузки (только stdlib: `smtplib` + `threading`).
Целевой сценарий (реальная доставка 50 msg/s через весь конвейер Postfix→Rspamd→Dovecot)
требует работающего стека и существующих домена/ящика, иначе Postfix просто отклоняет
получателя. Без них скрипт либо явно сообщает об этом, либо (с `MGATE_LOAD_ALLOW_REJECT=1`)
тестирует только пропускную способность приёма на порту 25 (RCPT может отклоняться — это
ожидаемо и не ошибка нагрузочного теста).

## Методология

1. **SMTP throughput** (`smtp_load.py`): N воркеров-потоков, каждый открывает SMTP-сессию на
   порт 25/587 и последовательно отправляет сообщения; скрипт считает msg/s, задержки
   (min/p50/p95/max) и долю ошибок. Выбран **чистый Python (smtplib)**, а не
   `smtp-source`/`postal`/k6, чтобы не требовать ничего сверх того, что уже есть на хосте
   (python3 доступен везде, где запускаются остальные скрипты этого
   репозитория) — компромисс: меньше "из коробки" фич, чем у специализированных инструментов,
   но воспроизводимо без дополнительных зависимостей.
2. **API/Webmail latency** (TODO(S2)/TODO(S5)): аналогичный HTTP-раннер на `/api/v1/*` и
   `/api/v1/mail/*` после появления этих API; методология та же (конкурентные воркеры,
   перцентили задержки), инструмент, вероятно, k6 (образ `grafana/k6`, без установки на хост) —
   решение отложено до появления реального API, т.к. сценарии зависят от конкретных путей.
3. **Профиль нагрузки**: старт с низкой конкурентности (5-10 воркеров) и постепенное
   повышение до появления ошибок/деградации — типичный подход поиска точки насыщения, а не
   единственный фиксированный прогон.

## Запуск

```sh
# Прямая доставка на порт 25 (нужен реальный домен+ящик либо MGATE_LOAD_ALLOW_REJECT=1
# чтобы просто измерить пропускную способность приёма/RCPT без реальной доставки).
python3 tests/load/smtp_load.py --host 127.0.0.1 --port 25 --rate 50 --duration 30 \
  --domain mail.example.com --to smoketest@mail.example.com

# Только измерить, что порт принимает соединения на заявленной скорости, без реальных ящиков:
MGATE_LOAD_ALLOW_REJECT=1 python3 tests/load/smtp_load.py --host 127.0.0.1 --port 25 --rate 50 --duration 10
```
