# Дорожная карта MGate

> Краткая версия на английском / Short English summary: This is the public roadmap for MGate,
> a self-hosted mail platform (Postfix + Dovecot + Rspamd + ClamAV + a closed backend + React
> frontend). It lists implemented capabilities, the Free/Pro feature split and directions under
> consideration, without pricing or internal business details. Versions follow CalVer
> `YYYY.M.N`; the first public release is `2026.10.1`. See `CHANGELOG.md` for released versions.

Этот документ описывает публичную дорожную карту проекта: что уже реализовано, как
распределены возможности между редакциями и какие направления рассматриваются дальше. Здесь
нет цен и деталей защиты лицензирования. История выпущенных версий — в
[`CHANGELOG.md`](../CHANGELOG.md) и в [GitHub Releases](https://github.com/mgate-server/mgate/releases).

## Версии и выпуски

- Версии — CalVer `YYYY.M.N`: год, месяц без ведущего нуля и номер сборки внутри месяца
  (с 1), например `2026.10.1`. Git-теги — `v2026.10.1`.
- Версия одна на весь продукт: все 10 образов (`ghcr.io/mgate-server/*`), Helm-чарт и
  backend выходят вместе под одним номером. Теги образов: `2026.10.1` (неизменяемый),
  `2026.10` (последняя сборка месяца), `latest` (последний релиз).
- **Первый публичный релиз — `2026.10.1`**; в него входят возможности из раздела
  «Реализовано». Точный состав каждой версии — в `CHANGELOG.md` и заметках релиза.
- Как обновляться и закреплять версию — [DEPLOYMENT.md](DEPLOYMENT.md) §5; модель публикации —
  ADR [0009](adr/0009-repository-split.md).

## Как устроена разработка

Проект развивается последовательными этапами. Каждый этап заканчивается проверяемой вехой —
работающей функциональностью, а не просто написанным кодом. Метки `TODO(S<N>)` в коде
указывают этап, к которому относится оставшаяся работа:

| Этап | Направление |
|------|-------------|
| S0 | Каркас: комплект развёртывания, образы, документация |
| S1 | Почтовое ядро |
| S2 | API и данные |
| S3 | Редакции и лицензирование |
| S4 | Панель управления |
| S5 | Веб-почта и личный кабинет |
| S6 | Тесты, безопасность, упаковка релиза |
| S7 | Pro-модули и защита от модификации |
| S8 | Масштабирование и упаковка (Helm, HA) |

## Реализовано

### Основа платформы
- **Почтовое ядро**: Postfix + Dovecot + Rspamd + ClamAV + Unbound, генерация DKIM-ключа
  (RSA-2048) и ручная ротация по кнопке, postscreen, ограничения частоты.
- **TLS-сертификаты**: по умолчанию самоподписанный сертификат; собственный сертификат
  (цепочка PEM и приватный ключ) загружается в админке и заменяется вручную. Реализован
  автоматический выпуск и продление через Let's Encrypt / ZeroSSL (HTTP-01) через ACME-клиент
  и фоновый воркер `AcmeRenewalJob`.
- **API и данные**: бэкенд с PostgreSQL + Valkey, Argon2id, RBAC (SuperAdmin,
  DomainAdmin, User), двухфакторная аутентификация (2FA / TOTP) при входе с резервными кодами,
  аудит-лог.
- **Редакции и лицензирование**: бесплатная редакция Community (1 домен), переход на Pro из
  админки по ссылке или одноразовому коду, короткоживущие подписанные лицензии с онлайн-
  продлением, обнаружение клонов, 72 часа работы без связи с сервером лицензий
  ([LICENSING.md](LICENSING.md)).
- **Панель управления**: дашборд, управление доменами и ящиками, администраторы доменов
  (Domain Admin) и квоты доменов, DNS-мастер с проверкой записей по кнопке, очередь сообщений,
  живые логи, статистика.
- **Веб-почта и личный кабинет**: 3-панельный клиент веб-почты с рендерингом писем в
  изолированном iframe и защитой от XSS/SSRF, контакты, автоответчик, пароли приложений.
- **Тесты и безопасность**: E2E-сценарии, нагрузочные тесты (целевые показатели: ≥ 50 писем/с
  и p95 ≤ 200 мс на 4 vCPU / 8 GB, методология — [TESTING.md](TESTING.md)), самопроверка по
  OWASP ASVS L2 ([SECURITY.md](SECURITY.md) §8), скрипты установки и проверки конфигурации.

### Pro-модули и защита от модификации
- **Pro-интерфейс**: страницы Pro в той же SPA под косметическим гейтом `<ProFeature>`; права
  всегда проверяются на сервере — Pro-эндпоинты отвечают `403`, пока Pro не активна
  (ADR [0018](adr/0018-spa-public-server-side-enforcement.md)). Модули, которые ещё не
  реализованы, помечены в интерфейсе «В разработке», а их API отвечает `501 not_implemented`
  (см. раздел «В разработке» ниже).
- **Защита от модификации**: закрытый бэкенд, независимая серверная проверка прав для каждой
  Pro-функции, документированная процедура обновления ([DEPLOYMENT.md](DEPLOYMENT.md) §5).

### Масштабирование и упаковка
- **Helm-чарт (`deploy/helm/mgate`)**: проверяется `helm lint` и `helm template`, поддержка
  внешних секретов (`ExternalSecrets`/`SealedSecrets`), ConfigMap, StatefulSet, сетевые
  политики.
- **Внешние сервисы**: подключение внешнего PostgreSQL и внешнего Valkey/Redis с одним
  endpoint (Redis Cluster и Sentinel не поддерживаются).

### Автоматизация DNS и защита данных
* **Для всех (Free + Pro)**:
  * **Мастер DNS**: готовые записи MX/SPF/DKIM/DMARC/MTA-STS/TLS-RPT/autoconfig, проверка
    опубликованных записей по кнопке «Проверить DNS» (фоновой проверки нет).
  * **Разовая «Автонастройка» DNS**: кнопка в мастере домена создаёт и исправляет записи через
    API Cloudflare или Selectel (других провайдеров пока нет).
  * Диагностическая утилита `mgate doctor` (проверка PTR, DNSBL, портов, прав ФС,
    сертификатов).
  * Резервное копирование на базе restic (cron / `make backup`) — [BACKUP.md](BACKUP.md).
* **Pro**: фоновая автоматическая сверка DNS-записей (`pro.dns_autopilot`) — в разработке.

### Репутация, аналитика и миграция
* **Для всех (Free + Pro)**:
  * **DMARC-аналитика (базовая)**: XML-отчёты загружаются вручную (автоматического приёма
    нет), сводка за 7 дней, статус готовности политики; IP источников маскируются.
  * Миграция почты по IMAP: администратор переносит пакет ящиков, пользователь — свой ящик
    (шаблоны для Яндекс 360, Google Workspace, Mail.ru и произвольный IMAP-сервер); перенос
    выполняется в фоне средствами Dovecot, статус виден в интерфейсе.
  * Автоматическая блокировка IP (защита от перебора паролей): временная блокировка IP после
    серии неудачных попыток, для повторных нарушителей — дольше.
* **Pro**:
  * **DMARC Intelligence** (входит в любую Pro-лицензию, отдельного флага нет): полные
    IP-адреса источников, история до 90 дней, скачивание исходных XML-отчётов. Имена хостов и
    география источников не определяются.

### Мультиарендность и брендинг
* **Для всех (Free + Pro)**:
  * Мобильная адаптация веб-почты (PWA-режим, service worker, адаптивное мобильное меню).
  * Расширенные пользовательские Sieve-фильтры в личном кабинете (поиск в теле письма, regex,
    заголовки спама, флаги IMAP).
  * Экспорт и импорт контактов в форматах vCard (RFC 6350 / RFC 2426) и CSV.
  * **Domain Admin**: администраторы доменов с ограниченным доступом только к своим доменам и
    квоты домена (число ящиков, объём) — в Community.
* **Pro**:
  * **`pro.branding`**: white-label — название продукта и логотип в шапке интерфейса и в
    заголовке вкладки. Favicon, акцентный цвет, ссылка поддержки и текст футера сохраняются, но
    пока не отображаются.

### Стабилизация
* Консолидация публичного API (`/api/v1`) и Pro API, сквозное тестирование бэкенда и
  веб-интерфейса.

## В разработке

Эти возможности **ещё не работают**: в интерфейсе они помечены «В разработке», а Pro-API
отвечает `501 not_implemented` и не возвращает вымышленных данных.

* **`pro.backup_center`** — Backup Center: веб-интерфейс расписаний, проверка целостности и
  пробное восстановление. Пока резервное копирование — restic из Community ([BACKUP.md](BACKUP.md)).
* **`pro.advanced_dashboard`** — Advanced Dashboard: тренды доставляемости, прогноз очередей и
  квот.
* **`pro.multi_tenant_rbac`** — расширенная мультиарендность и ролевая модель сверх базовых
  Domain Admin и квот (они уже есть в Community).
* **`pro.dns_autopilot`** — фоновая автоматическая сверка DNS-записей (разовая «Автонастройка»
  через Cloudflare / Selectel работает во всех редакциях).
* **`pro.priority_updates`** — приоритетные обновления.
* **Отказоустойчивость**: [HA и сценарии отказов](HA.md) — рекомендации по активному/пассивному
  Dovecot (Dovecot Director в версии 2.4 CE отсутствует), внешней БД и сетевому хранилищу;
  готовых автоматизированных профилей с несколькими репликами почтового стека нет.
* Автоматическая плановая ротация DKIM, плановая фоновая проверка DNS, переключение политики
  MTA-STS в режим `enforce` и принудительная проверка MTA-STS при исходящей доставке.
* SRS для пересылок и предупреждения о приближении к квоте ящика.

## Редакции: Free (Community) и Pro

| Направление | Free (Community) | Pro (годовая подписка) |
|---|---|---|

| **DNS** | Мастер DNS: готовые записи, проверка по кнопке, разовая «Автонастройка» (Cloudflare, Selectel) | **DNS-Автопилот**: фоновая сверка записей (`pro.dns_autopilot`) — в разработке |
| **DMARC и доставляемость** | **Базовая аналитика**: ручная загрузка XML-отчётов, сводка за 7 дней, IP маскируются | **DMARC Intelligence** (входит в любую Pro-лицензию): полные IP источников, история до 90 дней, исходные XML-отчёты — работает |
| **Резервное копирование** | CLI / cron-скрипты restic | **Backup Center** (`pro.backup_center`) — в разработке |
| **Аналитика и очереди** | Базовые счётчики за 24 ч | **Advanced Dashboard** (`pro.advanced_dashboard`) — в разработке |
| **Брендирование** | Копирайт MGate | **White-label** (`pro.branding`): название продукта и логотип — работает |
| **Управление доступом** | SuperAdmin, **Domain Admin** с квотами домена, пользователи личного кабинета | **Multi-tenant RBAC** (`pro.multi_tenant_rbac`): расширенная мультиарендность — в разработке |
| **Обновления** | Обычные релизы | **Приоритетные обновления** (`pro.priority_updates`) — в разработке |

## Рассматривается (без обязательств по срокам)

- All-in-one образ (`docker/aio`) для запуска без docker-compose — запланирован, не публикуется.
- Расширенный экспорт журнала аудита.
- Образы для `linux/arm64` — сейчас публикуются только образы `linux/amd64`.
- Лицензии для изолированных (air-gapped) сетей без доступа к серверу лицензий.
- Отдельная политика использования товарного знака «MGate».
